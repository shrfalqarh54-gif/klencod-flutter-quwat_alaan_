# قوة الآن 💪 — مشروع Flutter/Dart فقط

هذه نسخة مصدرية أولية مكتوبة بـ Flutter وDart فقط، ولا تحتوي على ملفات Kotlin أو Java مخصصة.

## مهم قبل البناء
- هذا مجلد مصدر Flutter، وليس APK جاهزًا.
- لم يتم اختبار البناء على جهازك أو داخل KleanCode IDE.
- أنشئ مشروع Flutter جديدًا من داخل IDE أو باستخدام Flutter SDK، ثم انسخ مجلد `lib` وملف `pubspec.yaml` إلى المشروع. احتفظ بمجلد `android` الأصلي الذي أنشأه Flutter؛ فهو يحتوي ملفات Android القياسية التي يحتاجها أي تطبيق Flutter.
- اسم الحزمة المقترح: `com.quwatalan.app`.
- عند استخدام الإشعارات على Android 13+ قد يلزم منح إذن الإشعارات من إعدادات التطبيق. جدولة المنبهات الدقيقة قد تتطلب السماح بها من إعدادات Android. سلوك التنبيهات عند إعادة تشغيل الهاتف أو فرض إيقاف التطبيق يختلف حسب إصدار Android والشركة المصنّعة؛ لا تعتبر هذه النسخة ضمانًا لمنبه يعمل في كل الظروف.

## الميزات الحالية
- واجهة عربية من اليمين إلى اليسار.
- إضافة المهام وتعديلها وحذفها.
- حفظ المهام محليًا باستخدام SQLite.
- منع حفظ المهام المتعارضة في الوقت نفسه.
- جدولة إشعار عند بداية المهمة ونهايتها عبر `flutter_local_notifications`.
- مساعد نصي محلي بسيط يجيب عن الوقت الحالي وعدد المهام، وليس نموذج ذكاء اصطناعي متصلًا.
- لا يوجد تحويل صوت إلى نص أو نص إلى صوت في هذه النسخة.

## المتطلبات
Flutter SDK حديث يدعم Dart 3.3 أو أحدث، واتصال إنترنت أول مرة لتنزيل الحزم.
